### Reflection ships Beam 1.0 weights (Apache 2.0)

- What happened: US lab Reflection announced Beam 1.0 weights on Hugging Face under Apache 2.0. Specs: sparse MoE, ~501.3B total / ~23.4B active per token, 1M-token context, text-in / text-out; BF16, FP8, and NVFP4 checkpoints plus a DFlash2 speculative-decoding drafter; open-sourced their training harness Mirror CLI. Official post says 40+ partners went live the same day (Ollama, Together, AWS, Azure, NVIDIA NIM, etc.); Ollama offered limited-time free US-hosted cloud access with ZDR.
- Why it matters: After yesterday’s Muse Spark Open and Nemotron 3.5, another US lab released commercially usable open weights with a more permissive license than Meta / StepFun custom licenses; Beam entered the open-weight front ranks on Agent Arena and similar boards.

### Liquid AI: d1-ultra tops the decision-model index

- What happened: Liquid AI released multimodal decision model d1-ultra: text / image in, one forward pass returning probabilities over options, no token generation; supports yes/no, choice, and score questions. List price about $0.042 per million input tokens (input only). Artificial Analysis says it leads Decision Index v1.0 at ~65.2, ahead of prior leader Jev by roughly 8+ points, with lower hallucination rate.
- Why it matters: Decision models serve structured answers (classify / route / risk / inspection), a different track from chat LLMs, with a third-party index to compare against.

### NVIDIA GEAR open-sources ASPIRE 1.0: coding agents write robot skills

- What happened: NVIDIA robotics lab GEAR (Jim Fan et al.) open-sourced ASPIRE 1.0 (Agentic Skill Programming through Iterative Robot Exploration). Frontier coding models write and repair robot control code from execution traces, depositing validated fixes into a reusable skill library instead of training another VLA. Official claims: after swapping in stronger backend models, sim benchmarks approach saturation (~99%); real bimanual demos include Rubik’s Cube. Apache 2.0 code at [NVlabs/ASPIRE](https://github.com/NVlabs/ASPIRE).
- Core post: [@DrJimFan](https://x.com/DrJimFan/status/2111128797181567466) (Oct 17 00:15 Shanghai, 34K views, 573 likes, 78 reposts, 99 replies).
- Verification: Method, benchmark narrative, and open-source claim checked against the [NVIDIA GEAR project page](https://research.nvidia.com/labs/gear/aspire/) and arXiv:2607.00272. 99% and Rubik’s Cube are lab self-tests / demos; real deployment still needs safe resets and success detection—Limitations section on the project page says so.
- Take: A “stronger models → better robot code” Physical Bitter Lesson story; the open framework and skill library matter more to practitioners than a single cube video.

### Elorian launches Glimpse: visual-reasoning preview

- What happened: Palo Alto startup Elorian (ex-DeepMind / Apple) launched first public model Glimpse, framed as “visual thinking”: mid-reasoning it can revisit images / video, zoom regions, and densify frame rate to track objects. Vendor evals claim parity or wins vs GPT-6 Astra on some chart-reasoning, short-video captioning, and manipulation-event tasks; pricing about $0.60 / $3.00 per million input / output tokens; API and chat live; weights not open.
- Core post: [@ElorianAI](https://x.com/ElorianAI/status/2111142036208501070) (Oct 17 01:07 Shanghai, 27K views, 441 likes).
- Verification: Positioning, pricing, and vendor table checked against the [Elorian blog](https://elorian.ai/blog/introducing-glimpse). “Beats Astra” is vendor self-test; parameter count and base-model name undisclosed.
