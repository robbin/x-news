# X AI 日报（2026-10-17）

## 1. AI 模型、产品与应用

### Reflection 正式开放 Beam 1.0 权重（Apache 2.0）

- 发生了什么：美国实验室 Reflection 宣布 Beam 1.0 权重上架 Hugging Face，协议为 Apache 2.0。规格为稀疏 MoE，总参数约 501.3B、每 token 激活约 23.4B，1M token 上下文，文本进文本出；提供 BF16、FP8、NVFP4 权重与 DFlash2 投机解码草稿模型，并开源自用 harness Mirror CLI。官方称与 40 多家伙伴同步上线（含 Ollama、Together、AWS、Azure、NVIDIA NIM 等）；Ollama 限时免费云托管并强调美国托管与 ZDR。
- 为什么值得关注：在昨日报 Muse Spark Open、Nemotron 3.5 之后，又一家美国实验室放出可商用开源权重，且许可比 Meta／阶跃的自定协议更宽松；Agent Arena 等榜单上 Beam 进入开源权重前列。
- 核心原帖：[@reflection_ai 官方](https://x.com/reflection_ai/status/2111079965529968798)（10-16 21:01，21.7 万浏览、804 赞、181 转、131 回复）；生态传播 [@ollama](https://x.com/ollama/status/2111087699574903061)（5.8 万浏览、248 赞）；训练／推理侧 [@NVIDIAAI](https://x.com/NVIDIAAI/status/2111089696025858212)（称在 GB300 NVL72 上训练，Blackwell Ultra 上可达超 70K tok/s/GPU，2.2 万浏览、571 赞）。
- 核验：参数、上下文、格式、Apache 2.0 与伙伴列表已对照 [Reflection 发布博文](https://reflection.ai/blog/beam-is-available)、[Hugging Face 模型卡](https://huggingface.co/reflection/Beam-1.0-501B-A23B)。知识截止写为 2026-06-30；BF16 约 1TB、NVFP4 约 280GB 为社区／HF 博文常用说法，以模型卡为准。「美国开源 DeepSeek 时刻」属营销话术。
- 判断：真正拉开差距的是许可（Apache）与 day-0 推理／微调生态，而不是再堆一个 500B 级 MoE；是否好用要等独立评测与真实 Agent 任务，而不是首发榜单位次。

### Liquid AI：d1-ultra 登顶决策模型榜

- 发生了什么：Liquid AI 发布多模态决策模型 d1-ultra：输入文本／图像，一次前向返回各选项概率，不生成 token；支持是非、多选、打分三类问题。官方报价约每百万输入 token 0.042 美元（只计输入）。Artificial Analysis 称其在 Decision Index v1.0 上以约 65.2 分居首，领先原榜首 Jev 系列约 8 分以上，并强调幻觉率下降。
- 为什么值得关注：决策模型是分类／路由／风控／质检一类「结构化答案」场景，和聊天大模型不是同一赛道；有独立第三方指数可对照。
- 核心原帖：[@ArtificialAnlys](https://x.com/ArtificialAnlys/status/2111052531166249039)（10-16 19:11，5.3 万浏览、545 赞）；官方跟进见 [@liquidai](https://x.com/liquidai/status/2111101102309736557)（4.5K 浏览，新发布，尚未形成高互动）。
- 核验：产品形态、定价与「不生成 token」已对照 [Liquid AI 博文](https://www.liquid.ai/blog/d1-ultra) 与文档；Decision Index 分数与排序为 Artificial Analysis 自测快照，属第三方评测而非厂商自报。
- 判断：这类模型适合「要不要拦、归哪一类、打几分」的流水线，不宜拿去写长文或写代码；榜首头衔会随新模型很快易主。

### NVIDIA GEAR 开源 ASPIRE 1.0：用编程 Agent 写机器人技能

- 发生了什么：NVIDIA 机器人实验室 GEAR（Jim Fan 等）开源 ASPIRE 1.0（Agentic Skill Programming through Iterative Robot Exploration）。思路是让前沿编程模型根据执行轨迹写／修机器人控制代码，把验证过的修复沉淀进可复用 skill library，而不是再训一套 VLA 权重。官方称换上更强后端模型后，仿真基准可接近饱和（约 99%）；真实双臂机器人演示包含解魔方等任务。代码 Apache 2.0，仓库 [NVlabs/ASPIRE](https://github.com/NVlabs/ASPIRE)。
- 核心原帖：[@DrJimFan](https://x.com/DrJimFan/status/2111128797181567466)（10-17 00:15，3.4 万浏览、573 赞、78 转、99 回复）。
- 核验：方法、基准叙述与开源声明已对照 [NVIDIA GEAR 项目页](https://research.nvidia.com/labs/gear/aspire/) 与 arXiv:2607.00272。99%、解魔方等为实验室自测与演示；真实部署仍依赖安全复位与成功检测，项目页 Limitation 节已写明。
- 判断：这是「模型变强 → 机器人代码变好」的 Physical Bitter Lesson 叙事；对从业者更有用的是开源框架与 skill library，而不是单次魔方视频。

### Elorian 发布 Glimpse：视觉推理预览

- 发生了什么：Palo Alto 初创 Elorian（前 DeepMind／Apple 背景）发布首个公开模型 Glimpse，定位「视觉思考」：推理过程中可回看图像／视频、放大区域、加密帧率追踪对象。官方自测称在部分图表推理、短视频字幕、操作事件理解等评测上达到或超过 GPT-6 Astra，价格约每百万输入 0.60 美元、输出 3.00 美元；API 与聊天界面已开放，权重未开源。
- 核心原帖：[@ElorianAI](https://x.com/ElorianAI/status/2111142036208501070)（10-17 01:07，2.7 万浏览、441 赞）。
- 核验：定位、价格与自测表已对照 [Elorian 博文](https://elorian.ai/blog/introducing-glimpse)。「超过 Astra」为厂商自测；参数量与基座名称未公开。
- 判断：卖点是「边想边看」的工具循环，而不是再做一个通用 VLM；独立榜单出来前先当预览版。
